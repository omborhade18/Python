# 05201382 - Open Source Tools and Frameworks with Python (practicals)

Install once:  pip install -r requirements.txt
Google Colab: open Python_Practicals_Colab.ipynb (File > Upload notebook) and run the cells.
Run any file:  python <file>.py   (from inside its folder)
Streamlit:     streamlit run 09_interactive_viz/9_2_streamlit_dashboard.py
Flask app:     python 12_ml_web_app/12_ml_flask_app.py  ->  /predict?feature=6

Practicals 10, 11 and 12 look for Zomato.csv, iphone-sales.csv and data.csv next to the
script; if the file is absent, sample data is generated so the script still runs.
Drop your real CSV in the same folder to use it.
